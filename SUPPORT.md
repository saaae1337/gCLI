# Куда писать, если что-то непонятно. У разных вопросов — разные места.

## Вопрос по использованию

[Discussions](https://github.com/saaae1337/gCLI/discussions) — как настроить
провайдера, что делает команда, как устроены прогоны и миссии.

Обсуждения не требуют оформления и остаются в репозитории: ответ может
быть полезен не только вам.

## Баг

[Issues](https://github.com/saaae1337/gCLI/issues/new?template=bug_report.md)
с шаблоном. Укажите версию (`gcli -v`), ОС и провайдера с моделью — без них
не разобраться.

## Уязвимость

Приватно, через Security → Report a vulnerability на
<https://github.com/saaae1337/gCLI/security/advisories/new>. Публичный
issue не подходит: уязвимость станет видна всем до релиза, который её
закроет. Подробности в [SECURITY.md](SECURITY.md).

## Не ваш случай

- Ошибки верстки, неудобные сообщения, «хочу ещё одну команду» — это
  feature request: <https://github.com/saaae1337/gCLI/issues/new?template=feature_request.md>
- Поведение модели, качество ответов, счёт у провайдера — к автору
  модели и провайдера.
- Вопросы по вашему проекту, который вы открыли в gcli, — в gcli.
