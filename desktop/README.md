# gCLI Desktop

Десктоп-оболочка gCLI: тот же агент, тот же движок миссий, тот же
сервер, что у терминала — но в отдельном окне, в фирменном стиле
«УГОЛЬ» (уголь + охра + индиго, маркеры ◆ и ⎿).

Архитектура — как у OpenCode: сервер один, клиенты разные. Терминал
(`gcli` без флагов) и это окно говорят с одним и тем же `gcli -serve`;
история, миссии и расход у них общие.

## Быстрый старт (режим разработки)

```bash
# 1. Собрать бинарник. ./build.sh лежит в корне репозитория и кладёт
#    результат в builds/ оттуда же — из desktop/ путь вверх:
./build.sh one

# 2. Зависимости и запуск:
cd desktop
npm install
npm start
```

Шаг 1 необязателен: если `gcli` уже стоит в `PATH`, Electron найдёт его
там. Собранный файл лежит в `builds/` под именем
`gcli-<версия>-<ос>-<арх>` — Electron узнаёт его по этому шаблону сам и
переименовывать не нужно.

Если бинарник всё-таки положить рядом с приложением, имя должно быть
ровно `gcli` (на Windows — `gcli.exe`), иначе Electron его не увидит:

```bash
mkdir -p desktop/bin
cp builds/gcli-*-linux-amd64 desktop/bin/gcli
```

Либо указать путь явно: `GCLI_BIN=/путь/к/gcli npm start`.

Приложение само поднимет `gcli -serve 127.0.0.1:8642`, дождётся
готовности и откроет окно с оболочкой.

## Режимы

| Режим | Как | Что происходит |
|-------|-----|----------------|
| Автономный | `npm start` | Electron сам запускает и гасит gcli -serve |
| Подключение | `GCLI_URL=http://127.0.0.1:8642 GCLI_TOKEN=... npm start` | окно присоединяется к уже работающему серверу |

Переменные окружения:

- `GCLI_BIN` — путь к бинарнику gcli (иначе: `desktop/bin/`, сборка, PATH);
- `GCLI_PORT` — порт автономного сервера (по умолчанию 8642);
- `GCLI_TOKEN` — свой токен вместо случайного;
- `GCLI_DEBUG=1` — печатать stdout сервера в консоль Electron.

## Сборка установщиков

```bash
# положить бинарник в desktop/bin/ (см. выше), затем:
npm run dist
```

electron-builder соберёт: AppImage и .deb (Linux), .dmg (macOS),
NSIS-установщик (Windows) — в `desktop/dist/`. Бинарник gcli кладётся
внутрь как ресурс и запускается оттуда.

## Файлы

- `main.js` — процесс Electron: поиск бинарника, запуск сервера,
  ожидание готовности, окно, внешние ссылки — в системный браузер;
- `preload.js` — пустой мост (contextIsolation, sandbox включены);
- `icon.png` — иконка в стиле «УГОЛЬ»: охра-ромб и индиго-контур;
- `package.json` — скрипты и конфиг electron-builder.
