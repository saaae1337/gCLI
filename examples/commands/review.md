description: ревью указанного файла или последних изменений
---
Проведи код-ревью с фокусом на качестве и безопасности:

1. Прочитай файл(ы), указанные в задаче, или `git diff` без аргументов.
2. Найди: ошибки логики, необработанные ошибки, утечки ресурсов, гонки данных,
   нарушения стиля проекта, дыры безопасности (инъекции, пути, secrets).
3. Отчёт по группам: «критично» → «важно» → «мелочи», для каждой находки —
   файл, строка и конкретное предложение по исправлению.
4. Не переписывай код сам, пока не попросят.

Файл/задача: $ARGUMENTS
