description: закоммитить изменения по правилам проекта
---
Сделай аккуратный коммит текущих изменений:

1. Посмотри `git status` и `git diff`, чтобы понять, что именно менялось.
2. Сгруппируй изменения логически — если они разнородные, предложи несколько коммитов.
3. Напиши сообщение в стиле Conventional Commits: `type(scope): краткое описание`.
   Типы: feat, fix, docs, refactor, test, chore.
4. Покажи мне финальное сообщение и список файлов ДО выполнения `git commit`.

Задача пользователя: $ARGUMENTS
