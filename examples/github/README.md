# GitHub-интеграция gcli

Готовые workflows для запуска gcli прямо в GitHub Actions. Оба требуют
секрет `GCLI_API_KEY` (ключ вашего провайдера: ZAI_API_KEY и т.д.) —
добавьте его в Settings → Secrets → Actions.

## review.yml — ревью PR агентом

Запускается на каждый PR. Агент читает дифф, оставляет комментарий
с разбором: риски, баги, предложения. Не блокирует merge — это подсказка,
а не контроль: для блокировки добавьте `exit 1` при серьёзных замечаниях
и `permissions: pull-requests: write`.

## mission.yml — автономная миссия по кнопке

Запускается вручную (workflow_dispatch) с параметрами: цель, режим,
срок, бюджет. Типовой сценарий: «пришли задачу на ночь — утром разберёшь
PR с изменениями». Изменения агент коммитит в отдельную ветку и открывает
PR — main не трогает, человека работу не застаёт.

## Ограничения

- Один запуск = один прогон: длительные миссии упираются в лимит
  job (6 часов у GitHub-hosted раннеров). Для extra-long-time используйте
  самохостед-раннер или цепочку миссий (`/mission chain`).
- Ключ даёт агенту доступ к вашему счёту: не ставьте секрет в fork-репозитории
  и не включайте его для pull_request от форков.
