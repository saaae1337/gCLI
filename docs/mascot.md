# Искра — кот gcli

Искра — рыжая кошка-помощник, маскот gcli. Она встречает в баннере,
сидит слева от поля ввода, пока вы печатаете, думает и работает вместе
с ИИ, мурчит от результата и фыркает на ошибках.

Кадры кота нарисованы по референсу проекта — три строки: уши, мордочка,
лапы. Эмоция живёт в трёх символах между скобками, поэтому анимация не
сдвигает интерфейс. Оформление подчиняется теме «Уголь»: контур — охра,
мордочка — тёплый белый, хвост-суффикс (`zZ`, `?`) — светлая охра.

```text
  /\_/\
 ( ^.^ )
  > ^ <
```

## Управление

| Действие | Как |
|----------|-----|
| включить / выключить | `/mascot on` · `/mascot off` |
| все состояния подряд | `/mascot demo` |
| реплика от кота | `/mascot say <текст>` |
| помахать хвостом | `/mascot wave` |
| текущий кадр и справка | `/mascot` |
| выключить через окружение | `GCLI_MASCOT=0` |
| грубый рисунок без юникода | запуск с `-ascii` |

## Живое поведение

Искра не статичная картинка — у неё есть распорядок:

- **моргает** — раз в ~6 секунд, пока вы думаете, что печатать;
- **скучает** — после 8 секунд тишины;
- **засыпает** — после 25 секунд без команд;
- **думает** — пока модель рассуждает;
- **работает** — пока идут инструменты;
- **мурчит** — после успеха: «готово! мурррр», «заслужила рыбку»,
  «задача решена, хвост трубой»;
- **фыркает** — при ошибке: «мяу! что-то не так», «шерсть дыбом»;
- **сердится** — после двух ошибок подряд: «опять?! шершавый день»;
- **прощается** — при выходе: «свернулась калачиком — до связи!».

## Терминалы без юникода

У каждого состояния есть ASCII-версия: кот продолжает жить, просто
рисуется грубее — `ω → w`, `° → o`, `□ → O`, `△ → o`, `Ò_Ó → >_<`.
Рамка облачка реплик тоже становится ASCII: `╭`/`╰` превращаются
в `+` и `-`.
